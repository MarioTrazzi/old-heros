Por que é fácil derivarWhy it's easy to remix

Três decisões de projeto fazem o trabalho pesado por você.Three design decisions do the heavy lifting for you.

  1. 1

    Regras separadas do visualRules kept apart from visuals

    A lógica do jogo não sabe como as peças são desenhadas. Dá para trocar modelos, texturas e cartas sem quebrar o combate, e mudar o combate sem abrir o Blender.The game logic doesn't know how the pieces are drawn. You can swap models, textures and cards without breaking combat, and change combat without opening Blender.

  2. 2

    Tudo em arquivos JSONEverything in JSON files

    Heróis, monstros, feitiços, itens e quests são dados. Um tema novo começa editando texto, não reescrevendo sistemas.Heroes, monsters, spells, items and quests are data. A new theme starts with editing text, not rewriting systems.

  3. 3

    A partida é uma semente e uma lista de jogadasA match is a seed and a list of moves

    Com a mesma semente, os dados caem do mesmo jeito. Guardando só as jogadas, o jogo refaz a partida inteira. É isso que dá replay, save e online sem código extra para cada um.With the same seed, the dice land the same way. By storing only the moves, the game can rebuild the whole match. That's what gives you replay, save and online play without extra code for each.

partida.json

{
  "semente": 48213,
  "jogadas": [
    ["Barbaro", "mover",   [6, 4]],
    ["Anao",    "atacar",  "Orc"],
    ["Mago",    "feitico", "pele_de_pedra", "Mago"],
    ["Mago",    "feitico", "bola_de_fogo",  "Orc"]
  ]
}

Exemplo ilustrativo. O formato real está no repositório.

match.json

{
  "seed": 48213,
  "moves": [
    ["Barbarian", "move",   [6, 4]],
    ["Dwarf",     "attack", "Orc"],
    ["Wizard",    "spell",  "stone_skin", "Wizard"],
    ["Wizard",    "spell",  "fireball",   "Orc"]
  ]
}

Illustrative example. The real format is in the repository.
